# Weary March: original procedural music study

76 BPM, D minor, approximately 39 seconds. 32 kHz / 16-bit mono PCM WAV.
0-12.6 s: restrained introduction; 12.6-25.3 s: fuller theme; 25.3-37.9 s: quieter work arrangement, followed by a closing tonic.

All melodies, synthesis and percussion were created for this project. No third-party recordings or game melodies were used. Brass/reed timbres are approximate procedural sketches, not sampled instruments.
This is an audition track, not a seamless loop, and is not connected to gameplay.
