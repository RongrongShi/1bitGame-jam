# Procedural typewriter sound study

Original procedural synthesis created for this project. No external recordings or AI audio service used.
44.1 kHz, 16-bit mono WAV. Three single-key variations and one audition track.
The preview begins with three isolated strikes, followed by a typing rhythm for “Sit down. This is your post now.”
These files are not connected to the game yet. Sound design draft; listen before choosing levels or timing.

Muted revision: `key-1-muted.wav` through `key-3-muted.wav` and `typing-preview-muted.wav`. Pitch lowered to 84%, with two 1350 Hz low-pass stages; original versions retained. Single-key peaks matched to the original 0.6 peak level.
