# Muted typewriter studies

Original procedural synthesis; no external samples.
44.1 kHz / 16-bit mono WAV. Every style includes three slightly varied keys.
Each preview uses the same layout: three isolated keys, then the same typing rhythm.

1. 01-low-mechanical: low mechanical body, subdued metal and spring return.
2. 02-hollow-wood: hollow wood-like body with a muted knock.
3. 03-heavy-thud: heavier low thump and slower decay.
4. 04-muffled-clack: strongly damped contact with quieter upper frequencies.

Individual key peaks are matched. `all-four-preview.wav` plays the four previews in this order with 0.6-second gaps.
No files are connected to gameplay yet; audition before choosing.
